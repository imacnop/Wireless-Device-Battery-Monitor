# BatteryHub (modified version)

> ⚠️ **Warning: this is a modified version of BatteryHub made by Robocnop and Imacnop.**
>
> The original project (`krisgfx9/Wireless-Device-Battery-Monitor`) is no longer available on GitHub.
> **You are welcome to use this version instead.** It keeps updating itself from this repository.

BatteryHub shows the battery level of your wireless devices (mice, keyboards, headsets, controllers,
phones...) in the Windows taskbar.

## Download

Get `BatteryHub-Setup-X.Y.Z.exe` from the [latest release](https://github.com/imacnop/Wireless-Device-Battery-Monitor/releases/latest)
and run it. Installed copies update themselves from this repository.

If you still run the original app, install this version once by hand: it cannot update itself across
to this repository.

## What this version adds

- **VR headsets and controllers**: the battery of the headset and of each controller, read from SteamVR
  while it runs (Valve Index, Vive, Meta Quest over ALVR / Virtual Desktop / Steam Link / Quest Link
  with SteamVR, ...). BatteryHub never starts SteamVR itself.
- **Nintendo Switch Pro Controller**: battery level without Steam running.
