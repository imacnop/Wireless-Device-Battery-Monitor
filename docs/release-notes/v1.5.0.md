## New

- **VR headsets and controllers.** BatteryHub now shows the battery of your VR headset and of each
  controller, read from SteamVR while it is running. It works with anything SteamVR knows: Valve Index,
  HTC Vive, and Meta Quest through ALVR, Virtual Desktop, Steam Link or Quest Link with SteamVR. The
  headset gets the Windows mixed reality headset icon, the controllers the gamepad icon. BatteryHub
  never starts SteamVR and loads nothing while it is closed.
- **Device requests go to GitHub.** *Request support for a device...* now opens a new issue in your
  browser with the device details filled in. Nothing is sent until you create the issue yourself.

## Fixed

- A Corsair headset paired to its receiver and plugged in by USB to charge was shown twice. It now
  shows once, under its own name (for example *Corsair VOID WIRELESS v2*).
- An iPhone paired twice with Windows (classic Bluetooth and Bluetooth LE) was shown twice. It now
  shows once.

## Changed

- The *Support the project...* menu entry and the installer's donation link are gone.

## Install

Download `BatteryHub-Setup-1.5.0.exe` below. If you already run a version from this repository, it
offers the update from its menu. Coming from the original BatteryHub? Install this version once by
hand; your settings and battery history are kept.
