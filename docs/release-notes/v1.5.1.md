## Fixed

- **iPhone shown twice with Phone Link.** When Windows names the iPhone's classic Bluetooth side
  just *iPhone* and its Bluetooth LE side *Alex's iPhone*, the phone appeared once from Phone Link
  and once from Bluetooth. It now shows once, as Phone Link names it.

## Install

Download `BatteryHub-Setup-1.5.1.exe` below. If you already run a version from this repository, it
offers the update from its menu. Coming from the original BatteryHub? Install this version once by
hand; your settings and battery history are kept.
